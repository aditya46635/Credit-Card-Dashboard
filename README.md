# Credit-Card-Dashboard
Power Bi Project
This project is an interactive Power BI dashboard designed to analyze credit card customer data and uncover insights related to revenue, income, interest earned, and customer behavior.
The dashboard enables business users to visualize performance metrics across demographics, professional categories, and regional dimensions, helping in data-driven decision-making.

Dashboard Highlights

The Power BI dashboard includes:

KPI Cards for Revenue, Total Interest, Income, and CSS.

Line chart for Revenue trends by time and gender.

Bar charts for Revenue by Marital Status, Income by Contact Type, Revenue by State, and Personal Loan by Profession.

Filters for Time period, Quarter (Q1–Q4), Card Type (Silver, Blue, Gold, Platinum), and Gender (Male/Female).
